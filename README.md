# OpsLibrary

A curated, structured **library of DevOps** learning resources for self-paced study.

This repository organizes lectures, tutorials, notes and projects (for hand-on practice) into a single, easy-to-navigate index - helping learners find quality DevOps resources without digging through scattered links.

> This is an ongoing effort - more resources will be added regularly.

---

## 📂 Structure

| Folder | What's inside |
|---|---|
| [`Lectures/`](./Lectures) | DevOps lecture videos, arranged in a recommended watch order |
| [`Notes/`](./Notes) | PDF notes **made by me** while learning each topic |
| [`Tutorials/`](./Tutorials) | Short how-to videos (WSL2, Dual Boot, AWS Free Tier, etc.) |
| [`Labs/`](./Labs) | Hands-on practice projects and links to related repos |
